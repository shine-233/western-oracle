# 神谕 · Western Oracle

一座**纯浏览器端**的西方占卜工具集：塔罗 · 西洋占星 · 合盘 · 行运 · 生命灵数 · 卢恩符文。

无后端、无账号、无埋点——所有计算与解读在你的浏览器内完成，数据不出本机。
全站 8-bit 像素画风：78 张牌面经像素化重绘，与像素小巫女「露娜」同一画风——点她可以听星星的悄悄话。

## 研究层（research/）

对标 `bazi-research` 的方法论：**公版原始文献 → 编号流水线 → 版本化数据集 → 站点消费**。

- 语料：Waite《Pictorial Key to the Tarot》1911 牌意（78张）、《盎格鲁-撒克逊卢恩诗》29节（Dickins 1915 英译）、Ptolemy 体系行星守护表——全部公有领域
- 流水线：`research/pipeline/01_fetch → 02_mine → 03_clean → 04_audit`，审计含防篡改抽查
- 消费：塔罗详情弹窗展示「Waite 原文牌意 · 1911」，符文页展示古英语卢恩诗原文
- 详见 [research/README.md](./research/README.md)

### 占星语义层（全部本地内置）

- **12 星座完整档案**：性格画像 / 行事方式 / 恋爱模式 / 事业天赋 / 阴影课题
- **12 宫位详解**：议题主题 + 一句话点题
- **相位含义库**：五大主要相位 + 小相位（半六合、半刑、倍半刑、梅花相、五分相…）
- **18 星体详解**：光体 / 个人 / 社会 / 时代行星 + 凯龙、莉莉丝、南北交、谷神·智神·婚神·灶神
- 组合文案引擎：任意「行星 × 星座」「行星 × 宫位」自动拼成通顺解读

## AI 解读（可选）

- 默认**无需任何配置**即可获得完整的本地规则解读
- 可选配置任意 OpenAI 兼容接口获得 AI 个性化解读：**流式打字机输出**、思考光球、**多轮追问**
- 密钥仅存 localStorage，浏览器直连服务商，本站不经手数据

## 双语界面 🌐

- 导航栏 **EN / 中** 一键切换，全站界面文案（导航、表单、按钮、提示、弹窗、设置页）完整双语
- 语言偏好持久化在 localStorage；月相名称等动态文案同样双语
- 占卜正文语料（塔罗释义、星座档案长文、解读引擎生成的段落）目前为中文优先，结构上已预留扩展位

## 质量保障 🧪

- [Vitest](https://vitest.dev/) 单元测试 49 条，覆盖：随机数与洗牌、生命灵数算法（含约减链）、78 张牌数据完整性、占星语料库完整性、星历计算与星盘生成（含南北交点 180° 校验）、合盘/行运解读引擎、历史记录存储上限、i18n 切换与插值、今日星历确定性、吉祥物体素数据完整性
- `npm run build` 同时执行 TypeScript strict 全量类型检查

## 技术栈

- Vue 3 + TypeScript（strict）+ Vue Router
- Vite 构建 + Vitest 单元测试
- [Three.js](https://threejs.org/) —— 首页体素 3D 吉祥物（按需懒加载）+ 后处理辉光
- [celestine](https://github.com/Anonyfox/celestine) —— 纯 JS 星历计算（经 NASA/JPL/Swiss Ephemeris 验证）：多宫位制、14 种相位、格局检测、小行星与莉莉丝
- 自研轻量 i18n（零依赖双语字典）
- 字体：[ZCOOL KuaiLe](https://fonts.google.com/specimen/ZCOOL+KuaiLe)（OFL）+ Press Start 2P（OFL），经 fontsource 自托管
- 随机数基于 `crypto.getRandomValues`
- GitHub Actions 自动部署到 GitHub Pages

## 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 产物构建（输出到 dist/）
npm run preview  # 预览生产构建
npm test         # Vitest 单元测试（一次性）
npm run test:watch  # 测试观察模式
```

## 部署到 GitHub Pages

1. Fork / 推送本仓库
2. 仓库 **Settings → Pages → Source** 选择 **GitHub Actions**
3. 推送到 `main` 即自动构建部署（见 `.github/workflows/deploy.yml`）
